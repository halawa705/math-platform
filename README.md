# منصة الرياضيات المتكاملة (Math Platform)

منصة تعليمية هندسية متخصصة بالكامل في مادة الرياضيات للمرحلتين الإعدادية والثانوية (الجبر، الهندسة المستوية والفراغية، حساب المثلثات، التفاضل والتكامل، الاستاتيكا والديناميكا، والإحصاء).

## المميزات المعمارية
- **مصادر الحقيقة الوحيدة (SSOT):** شجرة المنهج الدراسي، قاموس الرموز الرياضية العربية، وثوابت التخطيط المطبعي A4 في `src/core/ssot/`.
- **التمثيل الوسيط الموحد (IR):** فصل كامل بين البيانات الرياضية (`Math IR`, `Question IR`, `Booklet IR`, `A4 Layout IR`) وبين مصيرات العرض (`SafeKaTeX`, `Vector SVG`, `A4 Sheet Renderer`).
- **محرك الطباعة المتجهي A4:** استغلال مثالي للمساحات، شبكة اختيارات ذكية (`1×4`, `2×2`, `4×1`)، إرساء جانبي للأشكال الهندسية، وتحكم ذري بجميع إعدادات الصفحة.
- **تصميم صديق للهاتف أولاً (99% Mobile-First):** واجهة موحدة بوضع ليلي ونهاري (`Academic Royal Indigo & Emerald Teal`) مع بوابة دخول ذكية موحدة للطالب والمعلم.

## التشغيل المحلي

```bash
npm install
npm run dev
```
